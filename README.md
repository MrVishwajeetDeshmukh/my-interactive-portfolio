# vishwajeetdeshmukh.com

Personal site. React + Vite, plain CSS, no UI kit.

- `src/content.ts` holds all the text: jobs, projects, stack, education, links.
- `src/Pipeline.tsx` is the interactive Kafka consumer-group diagram (canvas, no libraries).
- `src/styles.css` has the colour tokens for light and dark at the top.

```
npm install
npm run dev      # http://localhost:8080
npm run build    # output in dist/, deployed by Netlify
```
